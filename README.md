# 📊 Telco Customer Churn Analysis

## 🔷 Project Overview
This project analyzes customer churn behavior in a telecom company using data analytics and machine learning techniques. The goal is to identify key factors affecting churn and predict customers likely to leave.

---

## 🔷 Objectives
- Perform data cleaning and preprocessing
- Conduct exploratory data analysis (EDA)
- Identify key churn drivers
- Build predictive model for churn
- Segment customers using clustering
- Create interactive dashboard for insights

---

## 🔷 Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Scikit-learn
---

## 🔷 Key Steps

### 1. Data Cleaning & Preprocessing
- Handled missing values
- Converted data types
- Encoded categorical variables
- Feature scaling applied

### 2. Exploratory Data Analysis (EDA)
- Churn distribution analysis
- Contract type vs churn
- Payment method vs churn
- Tenure and charges impact
- Correlation analysis

### 4. Machine Learning
- Logistic Regression model
- Churn probability prediction
- Risk categorization (High, Medium, Low)

### 5. Clustering
- K-Means clustering applied
- Customer segmentation into groups
- Cluster-based insights
